# 🦅 Hawk - Reportes Internos

Aplicación web de reportes desarrollada con Streamlit.

## Descripción
App interna para reemplazar proceso manual de reportes basados en Excel.

## Características
- Conexión directa a Google Drive
- Pantalla de resumen ejecutivo
- Fichas de clientes VIP
- Matriz de costos
- Comparativa de proveedores

## Tecnologías
- Streamlit
- Pandas
- Google Drive API

## Autor
Creada para optimizar reportes internos.
